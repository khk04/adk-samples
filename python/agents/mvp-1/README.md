# 🤖 MVP-1: 멀티 에이전트 기반 데이터 분석 및 리포트 생성 시스템

사용자 데이터를 분석하여 최적의 비즈니스 리포트를 생성하는 멀티 에이전트 시스템입니다.

## 📌 프로젝트 개요

MVP-1은 Google ADK(Agent Development Kit)를 기반으로 한 멀티 에이전트 시스템입니다. 3개의 전문 서브 에이전트가 협력하여 사용자 데이터를 분석하고, 맞춤형 질의를 생성하며, 전문적인 비즈니스 리포트를 제공합니다.

## 🎯 주요 기능

### 멀티 에이전트 아키텍처

1. **데이터 분석 에이전트** (`data_analysis_agent`)
   - 사용자 데이터 분석 및 비즈니스 인사이트 도출
   - 데이터 품질 평가 및 개선 권장사항 제공
   - 리포트 생성에 필요한 기초 정보 제공

2. **질의 생성 에이전트** (`query_generation_agent`)
   - 데이터 분석 결과를 바탕으로 한 맞춤형 질의 생성
   - 5단계 질의 프로세스 관리
   - 사용자 응답에 따른 동적 질의 조정

3. **리포트 생성 에이전트** (`report_generation_agent`)
   - 사용자 요구사항에 맞는 전문 리포트 생성
   - 비즈니스 관점에서의 데이터 해석
   - 실행 가능한 권장사항 제시

### 5단계 질의 생성 프로세스

1. **리포트 유형 확인** - 데이터 기반 추천 포함
2. **분석 기준 설정** - 사용 가능한 컬럼 기반
3. **데이터 범위 및 필터링** - 데이터 크기 고려
4. **리포트 스타일 결정** - 분석 유형에 맞는 스타일
5. **파일 형식 및 전달 방식** - 스타일별 최적 형식

## 🏗️ 아키텍처

### 멀티 에이전트 구조
```
mvp_coordinator (메인 코디네이터)
├── data_analysis_agent (데이터 분석)
├── query_generation_agent (질의 생성)
└── report_generation_agent (리포트 생성)
```

### 워크플로우
1. **사용자 요청 분석** - 요청 유형 파악 (데이터 확인 vs 리포트 생성)
2. **데이터 분석** - vdata 폴더의 데이터 분석 및 인사이트 도출
3. **질의 생성** - 5단계 맞춤형 질의 프로세스
4. **리포트 생성** - 사용자 요구사항에 맞는 전문 리포트 생성

## 🚀 주요 기능

### 1. 데이터 분석 에이전트
- **데이터 구조 분석**: 컬럼명, 데이터 타입, 고유값 수 분석
- **데이터 품질 평가**: 결측값, 이상치, 일관성 검증
- **비즈니스 인사이트 도출**: 매출, 수량, 제품, 지역별 분석 가능성 제시
- **분석 권장사항**: 데이터 특성에 맞는 분석 방향 제안

### 2. 질의 생성 에이전트
- **동적 질의 생성**: 데이터 분석 결과를 반영한 맞춤형 질의
- **5단계 프로세스 관리**: 순차적 질의 진행 및 응답 수집
- **사용자 친화적 인터페이스**: 명확한 선택지와 자연스러운 상호작용
- **최종 가이드 제공**: 완료된 요구사항을 바탕으로 한 리포트 생성 가이드

### 3. 리포트 생성 에이전트
- **전문 리포트 작성**: 비즈니스 관점에서의 데이터 해석
- **구조화된 리포트**: 요약, 분석 결과, 인사이트, 권장사항 포함
- **시각화 제안**: 데이터 특성에 맞는 차트 및 그래프 제안
- **실행 가능한 권장사항**: 구체적이고 실현 가능한 다음 단계 제시

## 🔧 기술 스택

- **Google ADK**: Agent Development Kit
- **Gemini**: Google의 AI 모델 (gemini-2.5-pro)
- **Pandas**: 데이터 처리 및 분석
- **Pydantic**: 데이터 검증 및 설정 관리
- **Poetry**: 의존성 관리

## 📊 사용 예시

### 1. 데이터 확인 요청
```
사용자: "데이터 확인해줘"
에이전트: "네, 데이터 상태를 확인해드리겠습니다! 📊"
→ data_analysis_agent 호출하여 vdata 폴더 분석
→ 분석 결과를 사용자에게 친근하게 설명
```

### 2. 리포트 생성 요청
```
사용자: "리포트를 만들어줘"
에이전트: "리포트 생성을 도와드리겠습니다! 📈"
→ data_analysis_agent: 데이터 분석
→ query_generation_agent: 5단계 질의 프로세스
→ report_generation_agent: 최종 리포트 생성
```

### 3. 5단계 질의 프로세스 예시
```
[1단계] 데이터 분석 결과를 바탕으로 리포트 유형을 추천합니다:
1. 매출 관련 데이터: sales_amount (평균: 1,250,000)
2. 제품 관련 데이터: product_category (5개 카테고리)
3. 지역 관련 데이터: region (3개 지역)

[2단계] '매출 분석' 리포트를 위한 분석 기준을 선택해주세요:
1. product_category별 분석
2. region별 분석
3. customer_type별 분석
...

[5단계] '상세 분석' 스타일의 리포트를 어떤 형식으로 받으시겠습니까?
1. PDF (인쇄용)
2. Excel (데이터 편집 가능)
3. HTML (웹 브라우저용)
...
```
