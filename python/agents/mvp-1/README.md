# 🤖 MVP-1: 사용자 데이터 기반 질의 생성 에이전트

사용자 데이터를 분석하여 최적의 리포트를 생성하기 위한 5단계 질의를 단계별로 처리하는 에이전트입니다.

## 📌 프로젝트 개요

MVP-1은 Google ADK(Agent Development Kit)를 기반으로 한 질의 생성 에이전트입니다. 사용자가 제공하는 데이터 파일(CSV 또는 Excel)을 분석하고, 리포트 생성에 필요한 모든 정보를 체계적으로 수집하기 위한 5단계 질의를 단계별로 처리합니다.

## 🎯 주요 기능

### 5단계 질의 생성 프로세스

1. **리포트 유형 확인** - 어떤 종류의 리포트를 생성할지 결정
2. **분석 기준 설정** - 데이터를 어떤 기준으로 분석할지 설정
3. **데이터 범위 및 필터링 조건 정의** - 분석할 데이터의 구체적인 범위 설정
4. **리포트 스타일 및 상세 수준 결정** - 리포트의 표현 방식과 상세도 결정
5. **리포트 파일 형식 및 전달 방식 확인** - 최종 리포트의 출력 형식 결정

**단계별 처리 방식:**
- 각 단계는 순차적으로 진행되며, 사용자의 응답을 받은 후 다음 단계로 자동 진행됩니다.
- 모든 단계가 완료되면 최종 리포트 생성 가이드가 제공됩니다.

### 핵심 도구

- **UserDataCheckTool**: 사용자 요청 분석 및 적절한 응답 제공
- **DataValidationTool**: 사용자 데이터 준비 상태 검증 및 품질 평가
- **DataAnalysisTool**: CSV/Excel 파일 분석 및 스키마 추출
- **QueryGenerationTool**: 6단계 질의 자동 생성 및 리포트 가이드 제공

## 🚀 주요 기능

### 1. 사용자 요청 분석
- **요청 유형 파악**: 사용자의 요청이 데이터 확인 요청인지 리포트 생성 요청인지 자동 분석
- **친근한 응답**: 사용자에게 적절한 안내 메시지와 다음 단계 제시
- **키워드 인식**: "데이터 확인해줘", "리포트를 만들어줘" 등의 자연어 요청 처리

### 2. 데이터 검증
- **파일 존재 확인**: 데이터 디렉토리 및 파일 존재 여부 검증
- **형식 검증**: CSV, Excel 파일 형식 지원 확인
- **구조 검증**: 필수 컬럼 존재 여부 및 데이터 타입 검증
- **품질 평가**: 결측값, 행 수, 데이터 일관성 평가
- **개선 제안**: 데이터 품질 향상을 위한 구체적 권장사항 제공

### 3. 데이터 분석
- **파일 형식 지원**: CSV와 Excel 파일 자동 감지 및 분석
- **스키마 추출**: 데이터 구조 및 컬럼 정보 자동 추출
- **통계 분석**: 기본 통계 정보 및 데이터 인사이트 제공
- **오류 처리**: 파일 형식 오류 및 데이터 오류 자동 감지

### 4. 5단계 질의 생성
- **1단계**: 리포트 유형 선택 (매출 요약, 성장 분석, 고객별 분석 등)
- **2단계**: 분석 기준 설정 (제품군, 지역, 고객군, 기간별 등)
- **3단계**: 데이터 범위 및 필터링 조건 정의
- **4단계**: 리포트 스타일 및 상세 수준 결정
- **5단계**: 리포트 파일 형식 및 전달 방식 확인

**단계별 처리 특징:**
- 각 단계는 순차적으로 진행되며, 사용자 응답을 받은 후 다음 단계로 자동 진행
- 모든 응답이 수집되어 최종 리포트 생성 가이드 제공

### 5. 실제 리포트 생성
- **포괄적인 분석**: 사용자 응답을 바탕으로 실제 데이터 분석 수행
- **자동 리포트 작성**: 데이터 개요, 주요 분석 결과, 인사이트, 권장사항 포함

- **파일 자동 저장**: `data/reports/` 폴더에 타임스탬프와 함께 자동 저장

### 6. 리포트 생성 가이드

#### 주요 기능

- **데이터 확인 요청**: "데이터 확인해줘", "내 데이터가 준비되어 있어?", "데이터 상태를 확인해줘"

### DataValidationTool 상세 기능

새로 추가된 데이터 검증 도구는 사용자의 데이터가 분석에 준비되어 있는지 종합적으로 검증합니다.

#### 검증 항목
- **파일 존재 확인**: 지정된 디렉토리에 데이터 파일이 있는지 확인
- **파일 형식 검증**: CSV, Excel 파일 형식 지원 확인
- **데이터 구조 검증**: 필수 컬럼 존재 여부 확인
- **데이터 품질 평가**: 결측값, 행 수, 데이터 타입 검증
- **일관성 검증**: 여러 파일 간 컬럼 일관성 확인

#### 검증 결과 제공
- **데이터 준비 상태**: 분석 가능 여부 판단
- **검증 요약**: 전체 데이터 현황 요약
- **파일별 분석**: 각 파일의 상세 분석 결과
- **문제점 식별**: 발견된 문제점 목록
- **개선 권장사항**: 데이터 품질 향상을 위한 구체적 제안

#### 사용 예시

**사용자 요청 분석:**
```python
# 사용자 요청 분석 도구 사용 (딕셔너리 형태 입력 지원)
check_result = check_user_data_request({
    'user_request': '데이터 확인해줘',
    'data_directory': 'data/generated_sales_data'
})

print(check_result.message)  # 친근한 응답 메시지
if check_result.should_validate:
    # 데이터 검증 수행
    validation_result = validate_data(check_result.validation_params)
```

**데이터 검증:**
```python
# 데이터 검증 도구 사용 (딕셔너리 형태 입력 지원)
validation_result = validate_data({
    'data_directory': '/path/to/data',
    'required_columns': ['월', '지역', '상품군', '매출액'],
    'min_rows': 10
})

if validation_result.is_data_ready:
    print("데이터가 준비되었습니다. 분석을 시작할 수 있습니다.")
else:
    print("데이터 준비가 필요합니다:")
    for issue in validation_result.issues:
        print(f"- {issue}")
```

**오류 처리 개선:**
- 딕셔너리 형태와 Pydantic 모델 형태 입력 모두 지원
- 상세한 오류 메시지와 디버깅 정보 제공
- 입력 타입 자동 감지 및 적절한 처리

## 🔧 문제 해결

### 자주 발생하는 오류 및 해결 방법

#### 1. `'dict' object has no attribute 'data_directory'` 오류
**원인**: Google ADK의 FunctionTool이 딕셔너리 형태로 매개변수를 전달할 때 발생
**해결**: ✅ 수정 완료 - 딕셔너리와 Pydantic 모델 형태 입력 모두 지원

#### 2. 데이터 디렉토리를 찾을 수 없는 경우
**원인**: `data_directory` 경로가 잘못되었거나 파일이 존재하지 않음
**해결**: 
- 올바른 경로 확인: `data/generated_sales_data`
- 파일 존재 여부 확인: `ls data/generated_sales_data/`
- 상대 경로 vs 절대 경로 확인

#### 3. 필수 컬럼이 누락된 경우
**원인**: CSV 파일에 필요한 컬럼이 없음
**해결**:
- CSV 파일의 컬럼명 확인
- 필수 컬럼: `['월', '지역', '상품군', '매출액']`
- 컬럼명이 다른 경우 `required_columns` 매개변수 수정

#### 4. 파일 형식 오류
**원인**: 지원하지 않는 파일 형식 또는 손상된 파일
**해결**:
- 지원 형식: CSV, Excel (.xlsx, .xls)
- 파일이 손상되지 않았는지 확인
- 파일 인코딩 확인 (UTF-8 권장)

- 오류 메시지에 포함된 상세 정보 확인
