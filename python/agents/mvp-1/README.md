# 🤖 MVP-1: 사용자 데이터 기반 질의 생성 에이전트

사용자 데이터를 분석하여 최적의 리포트를 생성하기 위한 5단계 질의를 자동 생성하는 에이전트입니다.

## 📌 프로젝트 개요

MVP-1은 Google ADK(Agent Development Kit)를 기반으로 한 질의 생성 에이전트입니다. 사용자가 제공하는 데이터 파일(CSV 또는 Excel)을 분석하고, 리포트 생성에 필요한 모든 정보를 체계적으로 수집하기 위한 5단계 질의를 자동으로 생성합니다.

## 🎯 주요 기능

### 5단계 질의 생성 프로세스

1. **리포트 유형 확인** - 어떤 종류의 리포트를 생성할지 결정
2. **분석 기준 설정** - 데이터를 어떤 기준으로 분석할지 설정
3. **데이터 범위 및 필터링 조건 정의** - 분석할 데이터의 구체적인 범위 설정
4. **리포트 스타일 및 상세 수준 결정** - 리포트의 표현 방식과 상세도 결정
5. **리포트 파일 형식 및 전달 방식 확인** - 최종 리포트의 출력 형식 결정

### 핵심 도구

- **DataAnalysisTool**: CSV/Excel 파일 분석 및 스키마 추출
- **QueryGenerationTool**: 5단계 질의 자동 생성 및 리포트 가이드 제공

## 🏗️ 아키텍처

### 에이전트 구조
- **단일 Agent**: `query_generation_agent` - 메인 질의 생성 에이전트
- **Gemini 모델**: `gemini-2.5-flash` - AI 모델
- **2개 도구**: 데이터 분석 도구 + 질의 생성 도구

### 워크플로우
1. **데이터 파일 업로드**: CSV 또는 Excel 파일 업로드
2. **데이터 분석**: 파일 구조 및 내용 분석
3. **1단계 질의**: 리포트 유형 확인
4. **2단계 질의**: 분석 기준 설정
5. **3단계 질의**: 데이터 범위 및 필터링 조건 정의
6. **4단계 질의**: 리포트 스타일 및 상세 수준 결정
7. **5단계 질의**: 리포트 파일 형식 및 전달 방식 확인
8. **리포트 가이드 생성**: 최종 리포트 생성 가이드 제공

## 🚀 주요 기능

### 1. 데이터 분석
- **파일 형식 지원**: CSV와 Excel 파일 자동 감지 및 분석
- **스키마 추출**: 데이터 구조 및 컬럼 정보 자동 추출
- **통계 분석**: 기본 통계 정보 및 데이터 인사이트 제공
- **오류 처리**: 파일 형식 오류 및 데이터 오류 자동 감지

### 2. 5단계 질의 생성
- **1단계**: 리포트 유형 선택 (매출 요약, 성장 분석, 고객별 분석 등)
- **2단계**: 분석 기준 설정 (제품군, 지역, 고객군, 기간별 등)
- **3단계**: 데이터 범위 및 필터링 조건 정의
- **4단계**: 리포트 스타일 및 상세 수준 결정
- **5단계**: 리포트 파일 형식 및 전달 방식 확인

### 3. 리포트 생성 가이드
- 사용자 응답을 바탕으로 최종 리포트 생성 가이드 제공
- 구체적인 분석 방향 및 리포트 구조 제안
- 데이터 특성에 맞는 맞춤형 가이드 생성

## 🔧 기술 스택

- **Google ADK**: Agent Development Kit
- **Gemini**: Google의 AI 모델 (gemini-2.5-flash)
- **Pandas**: 데이터 처리 및 분석
- **openpyxl**: Excel 파일 처리
- **Poetry**: 의존성 관리
- **Pydantic**: 데이터 검증 및 설정 관리

## 🛠️ 설치 및 실행

### 1. 초기 설정
```bash
# 프로젝트 디렉토리로 이동
cd /Users/khk/work/connev/adk-samples/python/agents/mvp-1

# 초기 설정 스크립트 실행
chmod +x setup.sh
./setup.sh
```

### 2. 환경 변수 설정
`.env` 파일을 생성하여 Google API 키를 설정하세요:
```bash
cp .env.example .env
# .env 파일 편집
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. 실행 방법

#### CLI에서 실행
```bash
# 메인 스크립트 직접 실행
python main.py
```

#### 웹 서버로 실행
```bash
# 웹 서버 시작
chmod +x start_web.sh
./start_web.sh
```

웹 브라우저에서 `http://localhost:8000`에 접속하여 사용할 수 있습니다.

## 🔍 질의 생성 예시

### 1단계: 리포트 유형
```
어떤 종류의 리포트를 원하십니까?
1. 매출 요약 (Sales Summary)
2. 성장 분석 (Growth Analysis)
3. 고객별 분석 (Customer Segmentation)
4. 상품군별 성과 분석 (Product Category Performance)
5. 지역별 성과 분석 (Regional Performance)

```

```
'매출 요약' 리포트를 위해 데이터를 어떤 기준으로 분석할까요?
예시: '제품군', '지역', '고객유형', '기간(월별, 분기별, 연간)' 등
현재 데이터에는 다음과 같은 컬럼이 있습니다: 월, 지역, 상품군, 매출액, 거래건수, 고객유형, 고객만족도
```
